# Languages (English, German)

The interface speaks English or German. The language is picked on the title screen or in the in-game menu, stored in `localStorage` (`f14lang`), and defaults to German when the browser asks for German.

## How it works

`@riskrts/shared` always speaks English. That keeps the simulation, the server and saves language-free, and lets a German guest read the error texts an English host sends (and the other way round). The client translates everything it shows:

- `t('Attack {0}', name)` (client code): translate an English template, then fill it. String arguments are translated too (region, power, unit names); numbers get a German decimal comma.
- `tx(text)` (texts from the simulation, a host or a server, e.g. feed lines, command errors, unit and technology names): looks the whole text up; failing that, matches it against every dictionary template that has `{0}` placeholders and translates the captured parts in turn.
- `useLang()` re-renders a component when the language changes; `langVersion()` lets non-React caches (map labels) notice.

Dictionaries are in `packages/client/src/i18n/de/` (English text or template → German), split by area. German templates can ask for a grammatical case: `{0:gen}`, `{0:dat}`, `{0:acc}`. That only changes the names in `de/decl.ts` (the powers; only the Ottoman Empire actually declines, the others are plain country names). A value that opens a sentence gets a capital letter.

The radio speaks German with the browser's German voice; the neural Kokoro voice only speaks English.

## Adding or changing text

1. Write the English in code as before. In client code wrap it: `t('…')`. Text that comes from `shared` is wrapped where it is shown: `tx(x)`.
2. Add the German to the matching file in `i18n/de/`. A shared template like `` `${R(e.region)} is cut off` `` becomes the key `'{0} is cut off'`. Every variant a conditional produces needs its own key (`formation` / `formations`).
3. Check: `I18N_REPORT=1 npx vitest run test/i18n-coverage.test.ts` (in `packages/client`) plays computer-only wars in German and lists every feed line, radio call and simulation error text still in English. In the browser, `__i18nMissing` holds what was shown untranslated this session.
